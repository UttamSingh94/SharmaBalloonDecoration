## 🚀 Live Preview Locally

You can preview the website locally using any of the following simple methods:

### Option 1: Double-Click
Simply double-click `index.html` in your file explorer to open it in your default web browser (Chrome, Safari, Edge, Firefox).

### Option 2: Using Node.js / npx (Optional)
If you have Node.js installed, open a terminal in this folder and run:
```bash
npx serve .
```
Or with Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 How to Publish to GitHub Pages

1. **Create a new repository on GitHub:**
   - Go to [github.com/new](https://github.com/new)
   - Name your repository (e.g. `sharma-balloon-decoration` or `username.github.io`).
   - Set visibility to **Public**.

2. **Initialize Git and push your files:**
   Open a terminal in this directory (`SharmaBalloonDecoration`) and run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Sharma Balloon Decoration website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - In your GitHub repository, go to **Settings** > **Pages** (under "Code and automation").
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
   - In 1–2 minutes, your website will be live at:
     `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/`
